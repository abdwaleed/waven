# Examples

The `examples/` folder contains scripts for common workflows:

- `examples/run_waven_parts.py`: run the major pipeline stages in sequence.
- `examples/pipeline_correlation_plots.py`: generate RF and tuning plots.
- `examples/wavelet_zarr.py`: convert full-model NPY wavelets to Zarr.
- `examples/example.py`: historical minimal usage example.

Run examples from the repository root so relative paths and editable imports are
resolved consistently.
